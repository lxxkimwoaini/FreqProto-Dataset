# FreqProto Dataset

Dataset repository for FreqProto, based on an extension of Time-MMD with Weather added for multimodal time-series forecasting across ten domains.

## Dataset coverage

- Agriculture
- Climate
- Economy
- Energy
- Environment
- Health
- Security
- SocialGood
- Traffic
- Weather

## Forecasting target

The forecasting target is the `OT` column. Other numerical variables provide historical inputs.
